# wuye-test-demo
## 智慧社区物业后台管理系统 测试项目文档
> 本仓库存放智慧社区物业平台全套测试资料，覆盖需求分析、测试计划、测试用例、缺陷管理、项目总结与页面原型

## 项目简介
本项目为"智慧社区物业后台管理系统手工功能测试练习项目"，完整模拟软件测试全流程：需求研读 → 制定测试计划 → 设计测试用例 → 执行测试提交缺陷 → 输出项目总结。
系统包含物业后台管理端与社区服务前台，面向社区物业人员、居民使用。

## 文件结构
- `社区服务平台后台需求文档.md`：业务需求梳理，明确系统功能、业务规则
- `社区服务平台后台测试计划.md`：测试范围、测试策略、资源安排、风险评估
- `智慧社区物业后台管理系统 - 测试用例清...`：全模块功能测试用例
- `社区服务平台 bug列表.md`：测试发现缺陷清单，包含缺陷描述、复现步骤、优先级、状态
- `社区服务平台总结.md`：项目测试总结，测试结果、问题分析、测试评估
- `智慧社区服务平台2.0.html`：物业后台页面原型
- `社区服务前台.html`：居民前台页面原型
- `前后台知识.md`：项目配套前后端基础知识点笔记

## 测试范围
智慧社区物业后台 + 居民前台Web功能测试，覆盖正常业务流程、异常输入、边界场景。

## 测试方法
等价类划分、边界值分析、错误推测法。

## 核心测试模块
业主信息管理、报修管理、公告管理、缴费管理、权限管理等物业核心业务模块。
